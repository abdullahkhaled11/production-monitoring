# إنتاج اليوم

أريد بناء تطبيق ويب احترافي Mobile First لإدارة ومتابعة إنتاج مصنع شنط.

التطبيق سيُستخدم بشكل أساسي من الهاتف المحمول بواسطة موظف يقوم بمتابعة الإنتاج في 4 خطوط إنتاج خلال اليوم.

المستخدم يذهب إلى كل خط إنتاج بشكل دوري، تقريبًا كل 15–30 دقيقة، ويقوم بعدّ الشنط التي تم إنتاجها منذ آخر زيارة، ثم يدخل الكمية في التطبيق.

التطبيق يجب أن يجعل عملية تسجيل الإنتاج سريعة جدًا وبأقل عدد ممكن من الضغطات.

مثال:

المشرفون:
أحمد
محمد
علي
محمود

أنواع الشنط:
شنطة مدارس
شنطة سفر
شنطة تمرين
شنطة جيش

مثال بيانات:

خط 1:

شنطة مدارس — 800 / 800

شنطة سفر — 650 / 1000

شنطة جيش — 400 / 800

خط 2:

شنطة مدارس — 1000 / 1000

شنطة تمرين — 350 / 500

خط 3:

شنطة سفر — 578 / 800

شنطة مدارس — 450 / 800

شنطة جيش — 700 / 1000

خط 4:

شنطة مدارس — 800 / 800

شنطة سفر — 600 / 800

شنطة تمرين — 250 / 500

شنطة جيش — 400 / 800

أنشئ سجلات إنتاج واقعية لكل شنطة حتى أستطيع تجربة واجهة سجل الإنتاج.

متطلبات تقنية

استخدم React.

Component-based architecture.

Mobile-first responsive design.

يجب أن يكون التصميم ممتازًا على:

360px
375px
390px
430px

ويعمل أيضًا على Desktop، لكن الأولوية القصوى للموبايل.

استخدم Local Storage أو IndexedDB.

لا تستخدم Backend.

لا تستخدم Authentication.

لا تضف Features غير ضرورية.

ركز على تجربة الاستخدام الفعلية داخل المصنع.

النتيجة المطلوبة

أريد Prototype كامل وقابل للتجربة وليس مجرد صفحة Static.

أريد أن أستطيع:

إضافة مشرف

تعديل مشرف

حذف مشرف

إضافة نوع شنطة

تعديل نوع شنطة

حذف نوع شنطة

اختيار خط

إضافة أكثر من شنطة لنفس الخط

تحديد المشرف لكل شنطة

تحديد الكمية المطلوبة لكل شنطة

إضافة إنتاج بشكل متكرر

تسجيل الوقت تلقائيًا

رؤية إجمالي كل شنطة

رؤية المتبقي

رؤية نسبة الإنجاز

إكمال الشنطة تلقائيًا عند الوصول للكمية المطلوبة

منع تجاوز الكمية المطلوبة

رؤية سجل كل الإضافات

تعديل عملية

حذف عملية

التراجع عن آخر إضافة

رؤية إجمالي إنتاج كل خط

رؤية تقرير اليوم

رؤية الأيام السابقة

اجعل التطبيق يبدو كمنتج حقيقي جاهز للاستخدام على الهاتف، وليس مجرد Demo بسيط.

ركز بشكل خاص على الـ Mobile UX وسرعة تسجيل الإنتاج.
